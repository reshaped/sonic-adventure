# 1ST_READ.BIN's census, which tools/census.py checks. Its rows explain the
# numbers 1ST_READ.BIN holds for RAM past its image, which ends at
# 0x8c8fd160, and those a GCC side holds at an address a table gives a name.
# A row is FILE START [END] COUNT, then a disposition, then the reason. The
# disposition is one of
#
#   anchor NAME FROM TO  an area, a buffer or a bound that keeps its address.
#                        NAME is the macro, symbol or field the sources name
#                        it by. Its extent runs from FROM up to TO, and the
#                        row's numbers lie in it or at TO, its end
#   placed SOURCE        a name symbols.txt gives, which SOURCE defines under
#                        GCC, so that the link places it
#   data                 no address, whatever its bits
#
# The row explains the COUNT numbers FILE holds that are START, or that lie
# from START up to END. Each lies in START's view of RAM: 0x0c, 0x8c or 0xac.
# Each lies on START's side of the image's end too. COUNT is a decimal
# number above 0, with no leading 0.
#
# file                                           start       end         count  disposition, then the reason

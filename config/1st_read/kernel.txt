# 1ST_READ.BIN's kernel: the functions its draws call for each node, model
# and meshset, grouped by the step of a draw that calls them. tools/ld.py
# lays them out first in the image's code, within the SH-4's 8 KB
# instruction cache, so that no two of their lines take one set of it. In
# SEGA's order of objects their lines can collide, and which collide moves
# with any code ahead of them. A row is SOURCE FUNCTION, SOURCE as the
# image's tables place it, so model.c's functions take src/draw/model.src.
# A row places the section that holds FUNCTION, so matrix_load_parent's
# places all of cache.src's code, its one P section. The near clip, which
# only a model with some points no farther than view.near takes, stays
# where its object lies.

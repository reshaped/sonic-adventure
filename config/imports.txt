# The names an image takes from outside that tools/spec.py can't bind by
# itself, and why. A row whose image is * binds the name in every image that
# takes it and has no row of its own for it. A row whose provider is its
# image makes the name a second name for the image's own symbol, with view -.
# Any other row imports the provider's symbol in the view given.
# 1ST_READ.BIN's imports from the images beside it are
# config/1st_read/imports.txt's, and no row here gives one of them again.
#
# A name needs a row where it is a second name, which no definition spells.
# It needs one where several images live with the image provide it, and not
# exactly one of their spans holds the name's address. An image provides a
# name where its objects export it, as tools/gcclink.py's exports() has it,
# and its own symbols.txt gives the name no other address. A name needs a
# row too where only a GCC guard or a source in gcc/ defines it, and the
# tables give it no address.
#
# An import's provider must be live with the image: a state of the memory
# contract holds both and lets one take names from the other. The exception
# is a hand-off, where the image reads the provider's file and then starts
# it, and the row's reason opens with hand-off:

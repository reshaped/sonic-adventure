# What each source is part of, its thing, and who reads what it computes,
# its bin. tools/parts.py reads the table for the checks that ask:
# tests/test_zam.py, which lets a file mark a function SHZ_FAST_MATH only
# where its bin is picture, engine/tests/boundary.py, which takes from it
# the directories of the backend and the runtime, the contracts, the adapter,
# the slice's runner and shim, and the Dreamcast's drawers, and the sources
# of play math and of the contracts, and tests/test_make.py, which takes play
# math's sources too.
#
# A row is PATH THING BIN. PATH is a file, or a directory, which ends in /,
# and a file takes the row with the longest PATH that is the file or a
# directory above it. Each C, C++ and assembly source, header and shader that
# git tracks under src/, sdk/, modules/, events/, loader/ and engine/ takes a
# row, and some such file takes each row: tests/test_parts.py holds both.
# The rows speak for the code a build compiles, the PC's shaders among it. A
# script, a make file or a linker script under a directory's row is none of
# the row's, and tools/parts.py gives it no thing or bin.
#
# The things and the bins are tools/parts.py's THINGS and BINS, which alone
# set their names. The two lists below say what each is, a name three spaces
# in and then its meaning, and tests/test_names.py holds them to the tool's:
# each name once, and no other.
#
# THING is one of:
#   game       SEGA's game, and the port's code in it: its fixes, its C in
#              place of the game's assembly, and 16:9, 60 fps, the overlay
#              and the skip
#   sdk        SEGA's libraries, and the port's C in place of their functions
#   play-math  the SH-4's float operations that play reads, as a host computes
#              them to the SH-4's bits
#   drawer     the Dreamcast's draws of the game's models, sprites and screen
#              draws, each sent before its call returns
#   recorder   a host's adapter: what turns the game's draws and sound into
#              the contracts' records and calls, and the client that gives a
#              capture's records to a backend
#   contract   the engine's C ABI, a game's part of it, and a capture's
#              records
#   backend    a machine's pictures and services: the Dreamcast's batch
#              kernels and frame owner, the PC's backend, the runtime's core,
#              which a machine that keeps its draws links, and what a host
#              gives the game's C in place of the SH-4 and SEGA's libraries
#   tool       a test's own program
#
# BIN is one of:
#   play     a game step reads what the file computes. A file whose bin isn't
#            known is play
#   picture  a game step reads nothing the file computes but what it brings
#            from outside the game, as a pad's bits, the clock's time or a
#            save's bytes. What lies below the draw calls is picture, and so
#            are the PC's services
#   both     the file holds a play half and a picture half, and its row ends
#            with a # comment that says what each is
#   none     neither: a test's own code
#
# path                         thing      bin

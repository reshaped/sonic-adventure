# The names the native slice's objects need that none of them defines, and
# what engine/tools/stubs.py writes for each: its docstring gives a row's
# form and each kind. make pc fails on a needed name with no row, on a row
# nothing needs and on a row whose kind doesn't fit its name's use, so a
# stub the game runs on is one a row here allows.
#
# A row is NAME KIND HOST REASON. HOST is linux or windows, the host whose
# objects need the name, or * for both. KIND is one of:
#   function     a function that reports its first call and answers 0, where the PC needs none of
#                what the console's does
#   zeros        64 KB of zeros, where the PC needs no more
#   address      a place in the domain that the matching side's tables give
#   engine       no stub: a call of the engine's, which the PC backend defines
#   unsupported  function's stub where an object calls the name, and zeros' where none does, for
#                what the game takes from the console's that the PC gives none of. The game runs
#                otherwise than on the console there
#
# REASON says what the name is on the console, what of the game needs it,
# and what the game makes of the stub. A line above a run of rows says
# what the run shares.
#
# name                               kind         host     reason
# SHC's intrinsic and its runtime's words

_BSG_END                             zeros        *        the word the start code keeps the end of bss in. sbInitSystem takes main memory's view from it, for the megabyte it hands syMallocInit, a stub too (src/system/sbinit.c)
_ctype                               unsupported  *        SHC's table of character classes, whose source engine/mk/native.mk leaves out of the slice's runtime. Only sscanf's scanner reads it, for the events' path editor (events/shared/sdk/_fmtin.c, events/shared/path_editor.c), and takes no character for a space or a digit

sa1_errno                            zeros        windows  _errno, by the name engine/mk/native.mk gives the game's on Windows, where the UCRT's _errno is a function
